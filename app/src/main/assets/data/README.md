# База данных сплавов (alloys_database.json)

## Структура

- **AL** — Алюминий (подгруппы: 1xxx, 2xxx, 5xxx, 6xxx)
- **CS** — Carbon Steel (ISO 15608: 1.1–1.4, 2.1–2.3, 3.1–3.2, 4, 6)
- **SS** — Stainless Steel (ISO 15608: 5.1, 5.2, 5.3, 5.4 + PH)

## Поля марки (grade)

| Поле | Описание |
|------|----------|
| `name` | Обозначение (AISI, EN, AA) |
| `chemicalComposition` | Химсостав (строка) |
| `awsName` | Обозначение по AWS |
| `gostName` | Обозначение по ГОСТ |
| `preheating` | Подогрев: `"-"` или температура в °C |

## Добавление новых марок

Добавить объект в массив `grades` нужной подгруппы.
